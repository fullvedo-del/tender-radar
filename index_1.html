Postavke spremanja (GitHub)

Roster i CV-jevi se čuvaju šifrirani u repozitoriju na GitHubu. Za spremanje stranici treba GitHub token koji smije pisati samo u ovaj repozitorij. Token se čuva samo u ovom pregledniku.

  1. Na GitHubu: slika profila, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Upiši naziv (npr. tender-radar) i rok trajanja (Expiration); kad token istekne, napraviš novi.
  2. Repository access: Only select repositories, izaberi tender-radar.
  3. Permissions, Repository permissions: Contents na Read and write. Ostalo ne mijenjaj.
  4. Generate token, kopiraj ga i zalijepi ispod.
